Drop royalty-free background tracks here (mp3, m4a, wav, ogg, flac).

Good free sources that allow monetized YouTube use:
- YouTube Studio → Audio Library (filter: "Attribution not required")
- Free Music Archive / Pixabay Music (check each track's license)

Calm, low-key instrumental beds work best under narration (ambient, piano, light strings, minimal percussion).
One track is picked per episode (stable per slug) and looped at `channel.json → music.volume` (0.1 by default).
Pin a specific track for an episode with `"music": "file.mp3"` in its storyboard.json.
